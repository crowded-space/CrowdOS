Cross-cutting notes:
- Auth: all routes rely on the global onRequest hooks (pinGate, authGate, tenant DB hook in create-app.ts:235-347); the domain itself performs no authorization and no workspace-ownership check (CM-003).
- Idempotency: resolvers/validate/browse are pure reads; attach set = replace semantics; clear = idempotent null write.
- Events: only routes emit (channel/category/workspace:mount-updated); no transactional outbox coupling; register-socket-server fans out room-scoped with payload.workspaceId fallback to observed channel rooms (global fallback only when neither channelId nor workspaceId is present - category events with null workspaceId can hit the global branch, CM-019).
- Error contract: resolvers never throw on bad data; validate never throws; browse throws only on missing path; attachers return {ok:false} and routes map to 400.
