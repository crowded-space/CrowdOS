# 01 Monorepo Bootstrap

## Goal
Create the empty but runnable project skeleton.

## Tasks
- [ ] Create root `package.json` with npm workspaces.
- [ ] Create `packages/server`.
- [ ] Create `packages/client`.
- [ ] Create shared TypeScript base config.
- [ ] Add root scripts: `dev`, `build`, `test`, `lint`, `typecheck`.
- [ ] Pick backend framework: Express or Fastify.
- [ ] Pick Tailwind version: v3 or v4.
- [ ] Add `.env.example`.
- [ ] Add `.gitignore`.
- [ ] Add root README with local setup steps.

## Done when
- `npm install` works.
- `npm run dev` starts server and client.
- Empty client page loads.
- Server health route responds.
