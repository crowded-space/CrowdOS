# 13 Mention System

## Goal
Control how user and agents target each other.

## Tasks
- [ ] Define mention syntax rules.
- [ ] Build frontend autocomplete for `@`.
- [ ] Insert mention metadata into composer state.
- [ ] Save mention metadata with messages.
- [ ] Parse mentions on message submit.
- [ ] Trigger target agent from valid mention.
- [ ] Add default behavior when there is no mention.
- [ ] Add validation for bad or unknown mentions.
- [ ] Add post-processing layer for agent-to-agent mentions.
- [ ] Add typo correction strategy if desired.

## Done when
- Mentions are structured data, not plain text only.
- User can reliably target agents and channels.
