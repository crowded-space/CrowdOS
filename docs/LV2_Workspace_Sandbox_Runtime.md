# CrowdOS Workspace Sandbox Runtime Spec

Version: `v0.1-alpha`

---

# Overview

The Workspace Sandbox Runtime is the foundational execution and collaboration layer for CrowdOS.

It provides:

* isolated virtual workspaces
* agent-native filesystem abstraction
* realtime synchronization
* event-driven orchestration
* multi-agent collaboration
* artifact exchange
* execution context tracking

The system is designed to function as a:

> Cognitive Workspace Runtime

rather than a traditional filesystem.

---

# Core Philosophy

Traditional workspaces are user-centric.

CrowdOS workspaces are:

* agent-centric
* orchestration-aware
* event-native
* semantically observable

Every workspace mutation is considered part of the system cognition lifecycle.

# Virtual Filesystem Layer

The system MUST NOT expose native filesystem access directly.

All operations pass through the Virtual Filesystem Layer.

---

# VFS Interface

```ts
interface VirtualFS {
  read(path: string): Promise<string>
  write(path: string, content: string): Promise<void>
  mkdir(path: string): Promise<void>
  delete(path: string): Promise<void>
  rename(oldPath: string, newPath: string): Promise<void>
  list(path: string): Promise<FileNode[]>
  stat(path: string): Promise<FileStat>
  watch(path: string): Promise<void>
}
```

# Event System

Workspace Runtime is event-native. Every mutation MUST emit events.

## Event Categories

```
workspace.created, workspace.deleted
file.created, file.updated, file.deleted, file.renamed
agent.joined, agent.left
artifact.created
execution.started, execution.finished, execution.failed
```

## Event Schema

```json
{
  "id": "evt_01",
  "type": "file.updated",
  "workspace_id": "ws_01",
  "path": "/src/App.tsx",
  "agent_id": "sparrow_runner",
  "timestamp": 1748000000,
  "metadata": {}
}
```
