### Summary

- **Confirmed HIGH defects:** F8 (default provider 403 + raw error UX), F10/F18 (per-workspace tool-call failures), F11 + F12 + F29 (Agent Studio save/X-Ray fail; tenant-scoping gap), F22 (DB-workspace messages silently invisible), F23 (DB-workspace agent assembly broken by preset ids), F28 (decorative emergency switch).
- **Confirmed MEDIUM:** F26 (raw SQL leakage in Repository panel), F4 (onboarding inconsistency).
- **Fixed during engagement:** F9 (model module registration).
- **Not reproducible / transient:** F2, F5, F7 (all on the :3000 dev session).
- **Passes:** first-run portal validation, channel creation UX, composer modes, edit/regenerate, agents board (local), permissions/security panels, screenlock validation, workspace menu, telemetry toggles, repository sandbox.
- **Dominant root cause corridor for the HIGH cluster:** tenant (per-workspace) resolution is complete for REST reads/writes (create-app.ts:235-318) but incomplete for (a) the socket-triggered runtime/tool/skill path and (b) the studio routes - plus DB-workspace seed data lacks a local-store mirror, so the local-first lookup path cannot see it.
